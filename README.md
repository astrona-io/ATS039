# Cloud Native Application Delivery (ATS039)

Kubernetes and Cloud Native Associate (KCNA) — Cloud Native Application Delivery, 16% of the published curriculum. This course is part of ATP008.

Concept lessons explain each official objective through concrete examples, diagrams and scenario reasoning. Every section begins with an introduction, and every module ends with a summary. Every module has a playground and a graded lab, every section has a capstone, and YAML knowledge checks include the correct answer, option feedback and learning-objective mapping.
