# Welcome To The Course

This course is for learners preparing for the Kubernetes and Cloud Native Associate (KCNA) examination. It covers Cloud Native Application Delivery, worth 16% of the published curriculum. The examination tests knowledge through multiple-choice questions. The explanations build the reasoning needed to choose an answer and explain why the alternatives do not fit.

At the end, you can explain and compare the concepts in Application Delivery, Debugging. Technical terms and acronyms are defined when they appear. Examples use ordinary applications; names such as `scout` and `probe` identify workloads rather than changing the technical meaning.

Each section begins with an introduction and learning outcomes. Each module starts with a short map, continues with teaching lessons and ends with a summary. Read the examples carefully, identify which component does the work, and predict what changes when a condition changes.

Each module has a playground for free practice and a graded lab, each section ends with a capstone lab, and original knowledge checks close each section and the domain. The knowledge checks give answer feedback. These exercises are not copied from the examination.
