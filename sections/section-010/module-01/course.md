# Build And Release Pipelines

This module develops the reasoning needed to trace source changes through build, checks and artifact publication.

## Learning Goals

- Trace source changes through build, checks and artifact publication.
- Explain what continuous integration checks.
- Distinguish continuous delivery from continuous deployment.
- Relate release identity to an immutable artifact.

## Before You Start

Read the examples as descriptions of system behavior. No cluster, account, laboratory or installed tool is required. Technical terms are defined where they are used.
