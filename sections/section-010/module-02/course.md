# GitOps And Deployment Configuration

This module develops the reasoning needed to explain declarative, versioned desired state.

## Learning Goals

- Explain declarative, versioned desired state.
- Describe pull-based reconciliation and drift correction.
- Compare Helm templating with Kustomize overlays.
- Identify what a GitOps controller cannot infer from repository state.

## Before You Start

Read the examples as descriptions of system behavior. No cluster, account, laboratory or installed tool is required. Technical terms are defined where they are used.

1. GitOps Reconciliation And Drift
2. Helm, Kustomize And Configuration Rendering
3. Summary
