# Safe Application Releases

This module develops the reasoning needed to explain rolling update behavior and readiness gates.

## Learning Goals

- Explain rolling update behavior and readiness gates.
- Compare rolling, blue-green and canary strategies.
- Identify evidence needed to promote or reverse a release.
- Explain compatibility limits of rollback.

## Before You Start

Read the examples as descriptions of system behavior. No cluster, account, laboratory or installed tool is required. Technical terms are defined where they are used.
