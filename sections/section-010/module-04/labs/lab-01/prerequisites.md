# Prerequisites

- The `astrona` command-line tool, installed and working (`astrona check` passes).
- A container engine that kind can use (Podman or Docker) with about 2 GiB of free memory.
- `kubectl`.
- `helm`, version 3 or 4, installed on the computer that runs the lab.

The lab starts a single-node kind cluster (Kubernetes 1.35) with the starting state described in the task.
