# Diagnosing Application Failures

This module develops the reasoning needed to distinguish process failure from application response failure.

## Learning Goals

- Distinguish process failure from application response failure.
- Use logs and termination evidence to form a diagnosis.
- Relate configuration and dependency access to application behavior.
- Explain correlation and safe reproduction of a failing request.

## Before You Start

Read the examples as descriptions of system behavior. No cluster, account, laboratory or installed tool is required. Technical terms are defined where they are used.
