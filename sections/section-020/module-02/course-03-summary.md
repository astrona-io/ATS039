# Summary

A release's declared version can differ from the artifacts and backends users actually reach. Scheduling, probes, endpoint selection and routing all affect rollout progress and served behavior.

A focused reproduction tests a supported explanation. Corrections belong in the intended configuration source, and verification checks both rollout state and application outcomes. Rollback requires compatibility with present data and dependencies; a previous image is not automatically a safe recovery plan.
