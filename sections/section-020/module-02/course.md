# Debugging Failed Releases

This module develops the reasoning needed to compare intended release identity with observed replicas and artifacts.

## Learning Goals

- Compare intended release identity with observed replicas and artifacts.
- Relate failed probes to rollout progress.
- Design a focused reproduce, correct and verify cycle.
- Choose rollback only when its compatibility requirements hold.

## Before You Start

Read the examples as descriptions of system behavior. No cluster, account, laboratory or installed tool is required. Technical terms are defined where they are used.

## Reading Order

1. Intended Versions And Observed Progress
2. Reproduce, Correct And Verify
3. Summary
